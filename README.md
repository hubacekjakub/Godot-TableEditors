# Godot Sheet Editor Plugin

This repository contains a minimal, work-in-progress Godot plugin for the Godot 4 editor.

- Adds a custom dock with a menu and editable grid.
- WIP: Features and UI are subject to change.

## Usage

Copy the `addons/sheet_editor` folder into your Godot project and enable the plugin in Project Settings > Plugins.
