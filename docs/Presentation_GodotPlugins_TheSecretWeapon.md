# Presentation: Godot Plugins: The Editor's Secret Weapon.

#### Jmeno: Jakub Hubáček
#### Firma: Flying Rat Studio

## English Summary

Editor plugins are amazing in every engine. Let's dive into the impact they can have, even for indie developers. Discover how using plugins can save you hours of manual work and make game dev fun again. I'll explain why plugin developers are such valuable team members and present a list of very handy plugins. Finally, I will demonstrate a case study of a specific problem and its solution using Godot plugins.

## Český souhrn

Editor pluginy jsou skvělé v každém enginu. Prozkoumejme, jaký dopad mohou mít i pro indie vývojáře. Pojďme si ukázat, jak může používání pluginů vrátit zábavu do vývoje odstraněním nudných repetitivních činností. Vysvětlím, proč jsou vývojáři pluginů tak cenění, a ukážu pár velmi šikovných pluginů, které lze při vývoji využít. Vše zakončím případovou studií konkrétního problému a mého řešení pomocí Godot pluginu.


## Core Points

**Plugins are cool** Plugins are the secret weapon even for indie developers. They may help automate repetitive tasks and eliminate human error.

**Plugin Power Showcase** Showcase of a selection of battle-tested Godot plugins that can immediately accelerate your workflow, improve code quality, and add missing engine features.

**Case Study** A practical deep dive into a real-world development problem and how a custom Godot Editor plugin provided an elegant, automated solution.

## Klíčové body

**Plugins are cool** Pluginy jsou tajnou zbraní i pro indie vývojáře. Můžou pomoct s repetitivními úkoly, přidat chybějící funkce nebo automatizaci.

**Plugin Power Showcase** Showcase ověřených pluginů pro Godot, které mohou zrychlit váš workflow, zlepšit kvalitu kódu a přidat chybějící funkce enginu.

**Case Study** Praktický pohled na reálný problém a ukázka toho, jak vlastní plugin pro Godot Editor může tento problém řešit.
